# KTV YouTube 系統

這是一個簡易的 KTV MVP：電腦負責播放 YouTube 影片，手機可作為遙控器來點歌與控制播放。

## 功能

- 建立 6 碼房號
- 電腦開啟播放器畫面
- 手機開啟遙控器畫面
- 貼上 YouTube 連結或影片 ID 點歌
- 播放 / 暫停 / 快轉 10 秒 / 倒轉 10 秒 / 下一首
- 顯示目前歌曲與待播清單

## 安裝與啟動

```bash
npm install
npm start
```

啟動後開啟：

- 首頁：`http://localhost:3000/`
- 電腦播放器：先建立房間，再開啟播放器連結
- 手機遙控器：用同一個房號開啟遙控器連結

## 使用方式

1. 在首頁按下「建立新房間」。
2. 在電腦上開啟播放器畫面。
3. 在手機上開啟遙控器畫面。
4. 在手機貼上 YouTube 影片連結或影片 ID。
5. 用手機控制播放與切歌。

## 注意事項

- 本專案使用 YouTube IFrame Player API，需要可連到 YouTube。
- 手機與電腦需能連到同一個服務位址。
- 目前是 MVP，歌曲資料只保存在記憶體，重啟伺服器後會清空。
